# 神話大戦 / YYMythology

剣と魔法と召喚術でユーラシアとアフリカの覇権を競うリアルタイムストラテジー。日本を含む地図で、最後の一国になると勝利する。地図上の勢力は架空の時代に共存する。

## 起動

Windows 版

```powershell
cargo run --release --locked --bin yymythology-win
```

ブラウザ版

```sh
bash build.sh
python -m http.server 8000 --directory dist
```

ビルド後に [ローカルのゲーム画面](http://localhost:8000/) を開く。

iPhone・iPadでは横向きでプレイする。タップで選択、長押しや画面上のボタンで命令、ピンチで地図を拡大・縮小できる。神名辞典は画面右上のボタンから開く。

## 召喚と魔法

- **神名辞典（F3）**から23の神話圏、69の神々・天使や祖霊を確認できる。自国領内の民を選んで辞典を開き、自国の神話圏から選ぶ。民1人を生贄に捧げ、糧180・木90・鉄90を使って都に召喚する。同じ神話を共有する全勢力で同時に3体まで。同じ神格の再召喚には、先に召喚された個体が倒れる必要がある。
- ギリシャではゼウスたち、ペルシャではマルドゥークたち、エジプトではラーたち、日本では天照大神たちが登場する。キリスト教・イスラムの勢力はそれぞれの天使を召喚する。
- **英霊（H）**は、自国領内で選んだ民を生贄に捧げ、自分の文明・民族に属する英雄を召喚する。全勢力に最低3人の候補があり、華北と江南の漢族など、同じ民族の地域勢力は候補を共有する。どの対局でも召喚できる。
- **魔法使い**は兵営で訓練する。通常攻撃と **Z** のファイヤーボールは詠唱なしで敵1体を射撃する。**X** のメテオは4秒詠唱し、射程内の敵建物のうち邑を優先して狙う。着弾地点の周囲にある敵建物にもダメージを与え、移動・停止で詠唱を中断できる。

タイ（スコータイ）、ビルマ（バガン）、マレー（マラッカ）を追加。クメールはアンコールが拠点。

## 魔神の危険域

北ユーラシアには氷の魔神、サハラ・中央アフリカなどには砂漠の魔神が出現する。勢力を問わず、円内にいるユニットは周期的に攻撃される。魔神は倒せないため、地図とミニマップの印を頼りに迂回するか、円の外まで退避する。

## アフリカの勢力

エジプトに加えて、フェニキア（カルタゴ）、ヌビア（クシュ）、マンデ（マリ）、ヨルバ（イフェ）、アクスム、スワヒリ（キルワ）、ショナ（グレート・ジンバブエ）を選べる。フェニキア、ヌビア、ヨルバ、ショナには専用の召喚枠がある。アクスムはキリスト教、マンデとスワヒリはイスラムの天使の召喚枠をそれぞれ共有する。さまざまな時代の文明と伝承を組み合わせた架空の設定。

地図の拡張に伴い、アフリカ追加前の対局記録を読み込むには旧版が必要。

文明の参考資料は [大英博物館のアフリカ諸王国年表](https://www.britishmuseum.org/sites/default/files/2024-04/African_Kingdoms_Timeline.pdf)、[ルーヴル美術館のカルタゴ資料](https://www.louvre.fr/decouvrir/vie-du-musee/carthage-et-son-sanctuaire-des-steles-pour-la-deesse-tanit)、[UNESCOのキルワ資料](https://whc.unesco.org/en/list/144/)。

## Cloudflare への公開

他のYYシリーズと同じ構成で、Workers Static Assets または Pages に `dist/` を配信する。

- **Workers** は `npm run deploy`。公開先の Worker 名は `yymythology`。
- **Pages** はビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定する。

Web版では追加画像を圧縮した別ファイルとして読み込む。ビルド時に配信ファイルがCloudflareの1ファイル25 MiB制限に収まるかを確認する。

## 出典

YYMongolia のコミット [`1d0faef`](https://github.com/ykwyuta/yyMongolia/commit/1d0faef) からゲーム本体、各種アセット、ビルド構成を引き継いだ。`docs/` は移植元の資料。59勢力それぞれに6種類の建物と8種類のユニット画像がある。建物は建設時の勢力の様式を保ち、同じ土地の出身と分かる専用兵はその土地の装備で表示する。召喚する神々や天使にはそれぞれの姿がある。勢力別の生成元PNGとプロンプトは `assets/faction-art/` に収録。画像を再梱包する場合は `python tools/import_faction_art.py` を実行する。

地図は [Natural Earth v5.1.2](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson) のパブリックドメインデータを使用。海岸線の収録範囲はヨーロッパ・アジア・アフリカ。`tools/geoprep.py` に Natural Earth の `ne_50m_admin_0_countries.geojson`、`ne_50m_lakes.geojson`、`ne_50m_rivers_lake_centerlines.geojson` の入ったディレクトリと出力先 `src/geodata.rs` を渡すと再生成できる。

勢力の入れ替えにより、セーブ形式が第3版になりました。第2版の対局は、旧版のゲームで再開してください。

アプリアイコンと起動画面の生成元画像・プロンプトは `assets/brand/` に収録。配布用ファイルの再生成は `python tools/import_brand_art.py`。
